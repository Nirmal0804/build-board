# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-09-16

### Added
- Monorepo structure with React (Vite) client and Express.js backend.
- Prisma schema for PostgreSQL with User, Post, Comment, and Like models.
- JWT-based authentication with bcrypt password hashing.
- RESTful endpoints for Auth, Posts, Comments, Likes, and User profiles.
- Frontend pages: Home, Explore Posts, Post Detail, Create Post, Edit Post, Profile, Login, Register, 404.
- Centralized error handling and authoritative server validation.
- Responsive modern UI design system with accessible components.
- Vitest and Supertest test suites for frontend and backend.
- GitHub Actions CI pipeline for linting, testing, and building.
- Open-source documentation: README, CONTRIBUTING, ARCHITECTURE, DEVELOPMENT, and 20 Good First Issues.
